| File | Purpose |
|---|---|

| `trace_matrix.csv` | Requirement → parent → design → test; includes split mapping. |
| `change_log.md` | New and changed requirements, including split IDs. |

## Split mapping

4 compound requirements were split into 4 atomic parts. The original ID keeps part 1;
parts 2+ use `ARCH-REQ-1001..ARCH-REQ-1004`. Use `Split_From` / `Split_Into` in `trace_matrix.csv` or the
`split_from` / `split_into` fields in `foc_requirements_extended.json` to follow the mapping.
